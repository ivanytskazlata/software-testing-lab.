# Практична робота: Автоматизоване тестування вебсайту за допомогою Playwright

## Тестований вебсайт
[Інтернет-магазин MAKEUP](https://makeup.com.ua/ua/)

## Опис автоматизованих перевірок
Скрипт `makeup.spec.js` відкриває головну сторінку сайту та виконує три базові перевірки:
1. **Перевірка URL-адреси:** підтверджує, що завантажилася саме українська версія сайту (`/ua/`).
2. **Перевірка заголовка сторінки (Title):** переконується, що заголовок вкладки браузера містить назву бренду `MAKEUP`.
3. **Перевірка видимості елемента навігації:** знаходить у меню категорію «Парфумерія» та перевіряє, що вона відображається на екрані.

## Інструкція із запуску тесту
Для запуску тесту на комп'ютері має бути встановлений **Node.js**.

1. Створіть папку проєкту та помістіть у неї файл `makeup.spec.js`.
2. Відкрийте Термінал у цій папці та виконайте команди для ініціалізації проєкту й встановлення Playwright:
   ```bash
   npm init -y
   npm install -D @playwright/test
   npx playwright install chromium
